INDEX.HTML

The index.html file is the landing page for the folder in which it is located. When it is in the root folder of your GitHub Course Repository, it is also the home page of your course website.

Each subfolder can have its own index.html landing page. If a folder does not have one, include the webpage filename in the URL.
