# CIS181 Course Website

This repository is the starting point for your CIS181 coursework.

## Lab starters

Each Applied Lab from 2-1 through 3-2 has its own prepared starter folder. Work only inside the folder for the current lab. Do not modify matching files from an earlier lab.

- `lab2-1` starts with the completed Block 1 Earth Science pages.
- `lab2-2` starts with the Lab 2-1 solution.
- `lab2-3` starts with the Lab 2-2 solution.
- `lab3-1` starts with the Lab 2-3 solution.
- `lab3-2` starts with the Lab 3-1 solution and adds its own landing page.

Each lab folder contains the files named in that lab’s instruction sheet. Keep the required folder names, then commit and push your changes so GitHub Pages can publish the correct lab URL.
